# ☁️ Cloud File Storage System

Welcome to the **Cloud File Storage System** 🚀

A web-based application that allows users to **upload, store, manage, and download files using cloud storage**. It provides secure and easy access to files from anywhere.

# 📌 Features

* ☁️ Cloud-based file storage
* 📤 Upload files
* 📂 View and manage stored files
* ⭐ Star important files for quick access
* 📥 Download stored files
* 🔗 Share files securely
* 🗑️ Delete files
* 🔍 Search and manage files
* 🔐 Secure user login
* 👤 User dashboard
* 📊 Storage usage tracking


# 🛠️ Technologies Used

* AWS
* AWS S3
* AWS IAM
* Web Development
* Python
* flask
* MySQL


# 🎯 Objectives

* Provide secure cloud-based file storage.
* Access files from anywhere.
* Reduce dependency on local storage.
* Make file management simple and efficient.

# ☁️ Cloud Integration

The system uses **Amazon S3** for storing files securely in the cloud.

```text
                  ┌───────────→ AWS S3
                  │              (File Storage)
User → Web Application → Python Backend
                  │
                  └───────────→ MySQL
                                 (User & File Data)

```
